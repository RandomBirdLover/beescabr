WHAT THIS FOLDER IS
===================

Builds the public website.

Writes to docs/, which is what GitHub Pages serves. This is the only folder in
the project whose output is visible to the public, so a mistake here is visible
to the public too.


THE FILES
=========

  publish_pages.R        assembles docs/ from the analysis outputs
  build_content_pages.R  the written pages (about, acknowledgements) as opposed
                         to the generated tables and maps
  citations.R            attribution for photographs and data sources


WHY SOME WEB PAGES ARE NOT BUILT HERE
=====================================

This is the confusing bit, so it is worth stating plainly.

About ten scripts in scripts/analysis/ also produce .html -- the occurrence
explorer, the plant explorer, the field guide, the bounty tables, the transect
map. They are NOT in this folder, and that is deliberate.

The line is: THIS FOLDER IS WHAT WRITES INTO docs/. Nothing else does.

An analysis script that produces a page is still an analysis. It writes into
data/analysis/<topic>/website/ beside the CSV of the same numbers, because it
belongs to its topic the way any figure does. publish_pages.R then copies those
pages into docs/ and wraps them in the site.

So:

    scripts/analysis/reference/bee_field_guide.R
        -> data/analysis/2026_generated/reference/field_guide/website/*.html
    scripts/website/publish_pages.R
        -> docs/*.html

If you are changing what a page SAYS, the fix is in the analysis script that
computed it. If you are changing how the SITE is assembled -- navigation, the
landing page, the wrapper -- the fix is here.


RUN IT WITH
===========

    source("scripts/run_publishing_materials_pipeline.R")

Run the analysis pipeline first -- this one only copies and wraps what that
produced, so anything stale there ends up on the site.

Colors and styling come from scripts/analysis/theme_beescabr.R, the same source
the figures use. Never write a hex code into a page template; reference a token,
so the site and the figures cannot drift apart.
